# SoccerMatchBetting

这是一个中文 Markdown 工作流项目，用于 2026 世界杯赛前信息整理、盘口快照记录、娱乐比分预测和赛后复盘。

第一版不做 Web 后台，不接数据库，不自动下注。核心是让智能体每次查询前先更新资料，再按统一模型输出两组比分，并在比赛结束后记录实际比分和预测偏差。

## 使用方式

常见提问方式：

```text
今天最近的世界杯比赛有哪些，更新盘口后给我两组比分
```

```text
帮我看墨西哥 vs 南非，盘口如下：...
```

```text
更新 2026-06-11 的实际比分，并复盘昨天预测准不准
```

智能体会按 `AGENTS.md` 的规则执行：

1. 先核对最新赛程和实际比分。
2. 优先读取你提供的盘口文本或截图。
3. 没有用户盘口时，联网查询公开信息。
4. 更新比赛文件。
5. 输出稳健比分和分歧比分。
6. 后续自动补充赛后复盘。

## 盘口范围

第一版只记录三类盘口：

- 胜平负
- 亚洲让球
- 大小球

如果盘口缺失，预测仍可进行，但必须降低信心等级，并明确标注资料缺口。

## 比分输出

每场比赛默认输出两组比分：

- 稳健比分：贴近基本面和盘口共识。
- 分歧比分：考虑平局、冷门、小胜或总进球偏移。

## 风险边界

本项目只用于娱乐预测和赛后复盘，不提供下注金额建议，不保证命中率，不做自动投注，也不把盘口信息解释为确定性结果。
